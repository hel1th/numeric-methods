# Численные методы (МАИ, 5 семестр)

Репозиторий с лабораторными работами по курсу «Численные методы».

## Структура проекта

- `lab1/` — Лабораторная работа №1: Линейная алгебра и спектральные задачи
  - [`lu.py`](file:///C:/Work/MAI/5sem/numeric_meth/lab1/lu.py) — 1.1: LU-разложение с выбором главного элемента, вычисление определителя, обратной матрицы и решение СЛАУ.
  - [`tridiagonal.py`](file:///C:/Work/MAI/5sem/numeric_meth/lab1/tridiagonal.py) — 1.2: Метод прогонки (алгоритм Томаса), проверка диагонального преобладания, невязка.
  - [`iterations.py`](file:///C:/Work/MAI/5sem/numeric_meth/lab1/iterations.py) — 1.3: Метод простых итераций (Якоби) и метод Зейделя, апостериорный критерий останова.
  - [`rotation.py`](file:///C:/Work/MAI/5sem/numeric_meth/lab1/rotation.py) — 1.4: Метод вращений Якоби для собственных значений и векторов симметрических матриц, анализ сходимости по итерациям.
  - [`qr.py`](file:///C:/Work/MAI/5sem/numeric_meth/lab1/qr.py) — 1.5: QR-разложение методом отражений Хаусхолдера, QR-алгоритм для поиска всех собственных значений (включая комплексные).
  - [`io_utils.py`](file:///C:/Work/MAI/5sem/numeric_meth/lab1/io_utils.py) — Парсинг текстовых файлов с тестовыми матрицами и системами.
- `lab2/` — Лабораторная работа №2 (в разработке).
- `tests/` — Набор автоматических тестов (`pytest`).
  - `tests/lab1/` — Входные данные и автотесты для всех заданий первой лабораторной.

## Запуск с помощью `uv`

### 1. Синхронизация зависимостей

```bash
uv sync
```

### 2. Запуск всех тестов

```bash
uv run pytest -v
```

### 3. Запуск демонстрационных программ

```bash
uv run python -m lab1.lu
uv run python -m lab1.tridiagonal
uv run python -m lab1.iterations
uv run python -m lab1.rotation
uv run python -m lab1.qr
```
